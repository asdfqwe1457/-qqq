# 同城到家预约上门【至尊版】带全套教程

源码获取：ym7k.com/19904/

这套同城到家至尊版上门预约系统，采用 **FastAdmin+ThinkPHP+Uniapp** 开发，一套前端源码支持微信小程序、公众号 H5、手机 H5，是家政、上门服务类 B2C 预约平台，支持商家入驻、师傅接单、用户线上下单预约、上门服务、订单核销、分佣结算，至尊版插件齐全，附带完整搭建教程、环境配置文档、安装视频，拿来即可搭建同城上门服务平台。

## 一、技术架构

后端：ThinkPHP + FastAdmin
前端：Uniapp，可打包微信小程序、H5、公众号端
数据库：MySQL
环境：Linux 宝塔面板（PHP7.4~8.1、Nginx）
交付包含：全套源码 + 数据库 + 搭建文档 + 安装视频教程 + 后台使用教程 + 前端打包教程

## 二、核心业务板块

可上架的服务品类：家政保洁、家电清洗、开锁换锁、管道疏通、上门维修、搬家拉货、月嫂育儿、上门美甲、上门按摩、同城跑腿等，后台自定义添加分类。

### 用户端（小程序 / H5 / 公众号）

- 微信一键登录，定位自动匹配附近服务商
- 服务分类、套餐选择、预约时间选择、填写上门地址
- 在线下单，支持余额支付、微信支付、线下到付
- 订单中心：待付款、待接单、服务中、待评价、已完成、售后
- 查看师傅信息、实时订单进度、师傅联系电话
- 优惠券、会员套餐、收藏服务、评价晒图
- 分享推广海报，分销拉新

### 师傅端（独立 H5 工作台）

- 师傅入驻申请，后台审核资质
- 接单大厅，支持指派接单 + 抢单模式自由切换
- 接收订单提醒、导航到用户地址
- 上传服务前后对比照片、完工提交、等待用户验收
- 佣金明细、余额、提现申请，查看历史订单与评价

### 商家入驻模块（至尊版亮点）

商家可以入驻平台，上架自家服务、管理自家师傅；平台设置商家佣金抽成；商家独立子后台，管理自己订单、师傅、营收。

## 五、完整业务流程

用户选择服务 → 填写地址 + 预约时间 → 下单支付 → 平台指派 / 师傅抢单 → 师傅上门服务 → 上传完工凭证 → 用户验收评价 → 佣金自动结算 → 师傅申请提现
